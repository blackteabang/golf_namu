모든 사람의 기기(스마트폰, PC)에서 참여자 정보와 경기 기록을 실시간으로 공유하고 서버에 영구 저장하려면 Firebase Realtime Database URL을 입력하세요.

❓ 무료 Firebase DB 주소 만드는 법 (1분)
  1. Firebase 콘솔 접속 후 프로젝트 만들기
  2. 좌측 메뉴 빌드 > Realtime Database 클릭 후 데이터베이스 만들기
  3. 보안 규칙에서 테스트 모드에서 시작 (읽기/쓰기 허용) 선택
  4. 상단에 표시된 https://...firebaseio.com 주소를 복사하여 여기에 붙여넣기
